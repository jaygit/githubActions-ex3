# GitHub Actions - Exercise 3

A demonstration repository showcasing advanced GitHub Actions workflow features including environment variables, job dependencies, custom actions, and secrets management.

## About

This repository contains example workflows that demonstrate:
- Multi-level environment variables (workflow, job, and step levels)
- Job dependencies and execution order
- Integration with custom GitHub Actions
- Secret handling and default environment variables
- Manual workflow dispatch triggers

Perfect for learning intermediate to advanced GitHub Actions concepts.
